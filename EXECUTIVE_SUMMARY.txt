PROBLEM:
  You have mcp-creative (divergent ideation) and mcp-consult (analytical critique)
  but they don't communicate. Users don't know when to switch modes. Ideas get
  stuck. Flow is broken by manual copy-pasting context.

SOLUTION:
  Build a cognitive bridge that logs meditation↔critique cycles, detects optimal
  mode-switch moments using neuroscience heuristics, and injects context seamlessly.

KEY INSIGHT:
  EEG research (Kounios, Jung-Beeman) shows brains have signatures of "ready to
  switch." We can detect these via proxies: semantic saturation (repeated concepts),
  pauses (incubation), novelty drop (stalled exploration), and critique plateaus.

ARCHITECTURE:
  
  mcp-creative  +  mcp-consult
           ↓
      ┌─────────────────────┐
      │   MCP-BRIDGE (NEW)  │
      │ ┌─────────────────┐ │
      │ │ Memory Store    │ │  Logs all meditation↔critique pairs
      │ ├─────────────────┤ │
      │ │ Insight Extract │ │  Concepts, novelty, overlap
      │ ├─────────────────┤ │
      │ │ Mode Switch     │ │  4 heuristics detect switch time
      │ │ Heuristics      │ │
      │ ├─────────────────┤ │
      │ │ Context Inject  │ │  Format insights for next cycle
      │ └─────────────────┘ │
      └─────────────────────┘

7 TOOLS EXPOSED:
  • bridge_start_session()              → Begin logging
  • bridge_log_meditation()             → Log meditation + extract insights
  • bridge_log_consult()                → Log critique + extract feedback
  • bridge_suggest_mode_switch()        → Get mode suggestion + reasoning
  • bridge_get_context_for_consult()    → Insights → consult prompt
  • bridge_get_critique_for_meditation()→ Critique → meditation context
  • bridge_get_session_trace()          → View session history

4 MODE-SWITCH HEURISTICS (grounded in EEG research):
  1. Semantic Saturation  (>60% concept overlap) → "Time to critique"
  2. Pause Detection      (5+ sec quiet)        → "Incubation moment"
  3. Novelty Drop         (<0.35 novelty)       → "Stuck; critique helps"
  4. Critique Freshness   (circling thoughts)   → "Evaluation plateau"

CALM UX:
  ✓ Only surface suggestions with confidence >= 50%
  ✓ Max 1-2 suggestions per session (every 5+ min)
  ✓ Contextual info, not modal interrupts
  ✓ Easy to ignore without friction

  M2 (Week 3):  Mode-switch heuristics (4 signals)

  M4 (Week 5):  Polish, docs, integration test

SUCCESS METRICS:
  ✓ Bridge detects saturation with >0.6 confidence

  ✓ Users rate suggestions 4.0+/5.0 relevance

RESEARCH FOUNDATION:
  • Guilford/Osborn:     Separated diverge/converge = better ideas
  • Kounios/Jung-Beeman: EEG signatures of insight (alpha) vs. analysis (gamma)
  • Weiser:              Calm technology (gentle, peripheral, not intrusive)
  • CritiqueLLM/CREA:    Bimodal systems (critique ≠ rejection; feedback loop)
  • Csikszentmihalyi:    Flow state requires <3 interruptions per session
